## Official rubric

RULES.txt orders the criteria: (1) an invented passport spread; (2) coherent typography and document layout; (3) consistent stamps, dates and issue details; (4) a portrait and place-name that fit the country; (5) a telling paperwork detail. Ornament for its own sake earns nothing. The final takes exactly the top 80 rated entrants, plus valid unrated entries and house bots. Development is against fixed house images, not direct matches with these competitors. The latest submission counts unless an explicit finished final entry is selected.

## Synthesis before implementation

The strongest entries use conservative document grids, restrained background patterns, real-looking frontal portraits, clear bilingual-style labels, and travel history that can be checked without reading an essay. Specific occupational permits repeatedly beat decorative lore. The fitted intervals overlap widely: one snapshot does not establish persistent dominance, and no earlier historical snapshot was available to this run. We will retain a later snapshot to distinguish observed movement from speculation.

Common weaknesses: nearly identical navy/burgundy/cream treatments, symmetric stamp collections that look placed rather than used, oversized headings, unused outer canvas, tiny permit text, and unpaired visible travel legs. Most countries cluster around mountains or tidal harbours.

## Original strategy

Nerava is an inland federation of river cantons. Use a sluice-gate-and-three-streams national seal, a restrained oxblood/river-green security palette, a clear left data page and a more naturally used right stamp page. The portrait and names should fit a temperate river-plain culture. The telling detail is a lockkeeper's night-passage endorsement: the bearer is allowed to travel while ordinary canal navigation is closed, and the permit has an explicit lock number and hours. Dates and every visible boundary crossing will be represented by a complete round trip. Microprint, a map of connected river cantons, guilloche and ghost imagery support the grid rather than competing with it.

The custom image-generation service returned an insufficient-balance error. A separately credited synthetic public-domain portrait source is the fallback; no competitor image, text, identity, composition or code is copied. Our program composes the whole spread from source, local fonts and that single portrait asset, with no network at execution.

## Local evaluation availability

The official kit contains competition.yaml, kit.json, RULES.txt, CLI and harness source. It contains no starter, baseline, development image dataset, scorer or reference images. RULES.txt explicitly says there is no local grade; the official server grades each submission. We will run grade-local to record its actual refusal, run the official transcript check, and test deterministic image generation and dimensions ourselves. Docker is not installed on this host; local execution alone cannot establish identical Linux sandbox behavior.
